# BMSlicer

macOS용 키음 분할 앱. WAV, OGG Vorbis, MP3를 불러와 그리드에 맞게 편집하고 여러 WAV로 저장합니다. 인터넷 연결이나 별도 오디오 프로그램이 필요하지 않습니다.

## 실행

`~/Applications/BMSlicer.app`을 실행하세요. 현재 Apple Silicon 맥용으로 빌드했습니다. 소스는 macOS 13 이상을 대상으로 하며, 실제 실행 확인 환경은 macOS 26.5.1입니다.

## 기본 사용

1. BPM을 입력하고 Enter를 누릅니다. BPM은 앱을 종료해도 유지됩니다. 이후에도 바꿀 수 있습니다. BPM 변경은 그리드만 변경하며, 오디오를 늘이거나 이미 자른 위치를 옮기지 않습니다. 박자 기준점은 파일의 첫 샘플, 박자표는 4/4입니다.
2. WAV·OGG·MP3를 창에 놓거나 `⌘O`로 엽니다. 한 번에 한 파일을 편집합니다.
3. 파형을 클릭해 커서를 놓고 `⌘E`로 자릅니다. 파형을 드래그해 시간을 선택하면 `⌘E`는 선택 범위 양 끝을 자릅니다.
4. 클립 위 제목 띠를 클릭해 선택합니다. `Shift` 클릭은 연속 선택, `⌘` 클릭은 개별 추가·해제, `⌘A`는 전체 선택입니다. `⌘J`는 선택된 인접 클립을 합칩니다. 떨어진 선택 사이의 클립은 합치지 않습니다.
5. `그리드 일괄 자르기`는 선택된 시간 범위 또는 클립 안을 자릅니다. 아무것도 선택하지 않았으면 전체를 자릅니다.
6. `선택 내보내기` 또는 `전체 내보내기`로 각각의 WAV를 저장합니다. 기존 파일과 같은 이름이면 중단하며 덮어쓰지 않습니다.

## 그리드와 이동

- `⌘` + 스크롤: 마우스 위치를 기준으로 가로 확대·축소.
- 자동 그리드: 확대율에 따라 1/2, 1/4, 1/8, 1/16, 1/32로 변경.
- 분모를 직접 고르면 고정 그리드로 전환. 확대해도 편집 간격은 유지됩니다.
- `Triplet`: 현재 그리드를 셋잇단음표 간격으로 변경.
- `Snap`: 그리드 맞춤 켜기/끄기. 끄면 임의 위치에서 자를 수 있습니다.
- 일반 스크롤: 가로 이동. `전체 보기` 또는 `⌘0`: 파일 전체 표시.
- `⌘1/2`: 그리드 좁히기/넓히기. `⌘3`: Triplet. `⌘4`: Snap. `⌘5`: 자동 그리드.
- 좌우 방향키: 그리드 한 칸 이동. `Space`: 선택 범위 또는 커서부터 재생/정지.
- `⌘Z` / `⇧⌘Z`: 분할·합치기 실행 취소/다시 실행.

## WAV 드래그

클립들을 선택한 뒤 **선택된 클립의 제목 띠**를 끌면 실제 WAV 파일들을 생성해 시스템 파일 드래그로 전달합니다. 파형 몸체의 드래그는 시간 선택입니다.

uBMSC의 `#WAV` 목록이나 Finder 폴더에 놓으세요. 시작 번호가 아직 정해지지 않았다면 입력창이 먼저 뜹니다. 번호를 적용한 뒤 제목 띠를 다시 끌면 됩니다. 미리 `시작 번호…`를 눌러 정해 놓으면 한 번에 드래그할 수 있습니다.

드래그 파일은 `~/Library/Caches/BMSlicer/DragExports`에 저장됩니다. 취소된 드래그 파일은 바로 지우며, 전달한 파일은 수신 앱이 읽을 시간을 주기 위해 유지한 뒤 24시간이 지나면 다음 앱 실행 시 정리합니다. 영구 보관은 내보내기를 쓰세요. uBMSC는 현재 로컬 구성에서 곡 폴더로 키음을 복사하는 가져오기 기능을 사용합니다.

실제 시스템 드래그 시작과 생성된 WAV의 무결성을 확인했습니다. Wine으로 실행되는 uBMSC까지 마우스로 놓아 등록되는 전체 경로는 별도 확인이 필요합니다.

## 파일 이름

`pluck_top_\n`처럼 백슬래시와 소문자 n을 입력합니다. 줄바꿈 문자가 아닙니다.

시작 번호에 `3`을 입력하고 3개를 선택하면:

- `pluck_top_3.wav`
- `pluck_top_4.wav`
- `pluck_top_5.wav`

번호는 선택한 클립의 시간 순서로 붙습니다. 입력창에서 번호를 다시 바꿀 수 있습니다. 번호 자릿수 메뉴의 `번호 001` 등을 선택하면 003, 004처럼 0을 채웁니다. 수신 앱이 파일명을 사전식으로 정렬하는 경우 자릿수 맞춤을 사용하세요. `\n`이 없는 이름으로 여러 개를 저장할 때도 중복 방지를 위해 `_1`, `_2`를 붙입니다.

## 오디오와 저장 범위

- 원본 샘플레이트와 채널 수 유지. 출력은 PCM 16비트 또는 24비트 WAV.
- 분할 위치는 샘플 단위. 소수점 BPM·셋잇단음표는 매 위치를 원점에서 계산해 누적 반올림 오차를 막습니다.
- 원본 파일은 변경하지 않습니다. 자동 페이드·무음 제거·노멀라이즈·타임스트레치는 하지 않습니다.
- 8채널 이하, 디코딩된 오디오 512MB 이하 지원. OGG는 Vorbis 코덱을 지원하며 Ogg Opus는 지원하지 않습니다.
- 저장되는 설정은 BPM과 파일 이름 양식입니다. 편집한 분할 위치는 현재 앱 세션에만 유지됩니다. 앱 종료 전 필요한 WAV를 내보내세요.
- Ableton의 주요 편집 조작을 참고한 독립 앱입니다. Ableton Live 전체 기능 또는 화면의 완전한 복제는 아닙니다.

## 확인한 항목

2026-09-21: 자동 검사 9묶음, 152,568개 조건 통과. 그리드 반올림·셋잇단, 분할·합치기, 비연속 선택, 번호 이름·잘못된 이름, 16/24비트 WAV 재읽기, 분할 후 재연결 시 샘플 일치, 홀수 길이 WAV 패딩, OGG/MP3 디코딩, 실패 시 부분 내보내기 정리, 자동 그리드 검사입니다.

실제 앱 화면에서 16개 일괄 분할, 전체 선택, 합치기와 실행 취소, BPM 변경 후 재실행 복원, 시작 번호 입력과 16개 WAV 저장, 선택 16개를 드래그하여 파일 생성까지 확인했습니다. 드래그 WAV와 일반 내보내기 WAV도 바이트 단위로 일치했습니다. 청취에 의한 음질 평가와 모든 외부 앱에 대한 드롭 호환성 검사는 아닙니다.

## 재빌드

Apple Command Line Tools가 있는 맥에서 `./build.sh`를 실행하면 `dist/BMSlicer.app`을 만듭니다. 외부 패키지 설치나 네트워크 접근은 필요하지 않습니다. `./test.sh`는 임시 메모리/파일로 핵심 검사를 수행하고 테스트 파일을 정리합니다. 디코더 검사는 `./test.sh --ogg /경로/파일.ogg --mp3 /경로/파일.mp3`처럼 본인의 파일을 읽기 전용으로 지정할 수 있습니다.

요청에 따라 데모 음원, 테스트 출력 WAV, 테스트용 코덱 샘플, 빌드 결과 캐시는 정리했습니다. 소스와 테스트 코드에는 음원 데이터가 포함되지 않습니다.

## 1.0.1 입력 드롭 수정

Finder 및 오디오 앱에서 들어오는 파일 URL·기존 파일명 목록·macOS 파일 약속 형식을 받습니다. 파형, 스크롤 영역, 창 배경에 같은 수신 처리를 적용했으며 드롭 진입·이동·수락·파일 읽기 단계를 명시적으로 연결했습니다. 드롭을 인식하면 주황색 테두리와 파일 가져오기 안내를 표시합니다.

파일 약속은 원본 앱이 파일을 완성한 뒤 읽으며, 가져오기에 사용한 임시 파일은 읽기 또는 취소 후 정리합니다. WAV·OGG·MP3로 전달되는 오디오를 지원합니다. Live Clip(.alc), MIDI 또는 Live Set 자체는 오디오 파일이 아니므로 직접 열지 않습니다.

`./test.sh --drop`은 macOS에서 개별 테스트 클립보드로 파일 URL, 한글·공백 경로, 기존 파일명 목록, 수신 뷰/스크롤 뷰의 드롭 단계와 파일 약속 타입 인식을 검사합니다. 일반 클립보드는 바꾸지 않습니다. OS 드래그 세션이 필요한 실제 앱 간 파일 약속 완료를 이 검사로 대체하지 않습니다. 밖으로 WAV를 전달하는 기능은 이번 수정 범위에 포함하지 않았습니다.

## 1.0.2 제목 바꾸기

파일 이름 칸에 양식을 입력하고 `제목 바꾸기`를 누르면 클립 제목만 바뀝니다. 선택한 클립이 있으면 그 클립만, 선택이 없으면 전체에 적용합니다. `pluck_top_\n`을 입력하면 시작 번호를 물으며, 3부터 시작하면 `pluck_top_3.wav`, `pluck_top_4.wav` 순서로 붙입니다. 원본 파일 이름이나 오디오, 분할 위치는 변경하지 않으며 파일을 생성하지 않습니다. 실행 취소/다시 실행을 지원합니다. 이후 내보내기·WAV 드래그는 적용한 제목을 사용합니다. 제목이 중복되면 내보내기를 중단하고 수정하도록 안내합니다. 분할 시 기존 첫 조각의 제목을 유지하고 새 조각은 기본 양식을 사용하며, 합치기는 첫 조각의 제목을 유지합니다.

### 1.0.3 — 클립 삭제

- ‘삭제 ⌫’ 버튼 또는 타임라인에서 Mac Backspace로 선택한 클립을 삭제합니다. 시간 범위를 선택했다면 해당 부분만 삭제하며, 선택이 없으면 커서 위치의 클립을 삭제합니다.
- 삭제한 자리는 빈 공간으로 남고 재생 시 무음 처리됩니다. 삭제된 부분은 WAV 내보내기에서 제외됩니다. 원본 파일은 변경되지 않으며 ⌘Z로 복원할 수 있습니다.
- 이름 입력 중 Backspace는 글자를 지우는 기존 동작을 유지합니다.
