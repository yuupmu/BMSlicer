# Third-party component

OGG Vorbis decoder: stb_vorbis v1.22, Sean Barrett and contributors.
Source: https://github.com/nothings/stb/blob/master/stb_vorbis.c
Downloaded 2026-09-21. The unmodified source contains its complete MIT/public-domain dual license at the end. This application uses the MIT option.

The OGG test fixture comes from the existing local uBMSC test-data directory. The MP3 test fixture comes from Homebrew's local test fixtures. Test fixtures are not distributed inside the application.

Interaction references:
- https://www.ableton.com/en/manual/arrangement-view/
- https://www.ableton.com/en/manual/live-keyboard-shortcuts/

BMSlicer is independent software and is not an Ableton product.

MP3 decoder: minimp3 by lieff and contributors, CC0 / public domain.
Source: https://github.com/lieff/minimp3 (minimp3.h, minimp3_ex.h), downloaded 2026-09-21. Full notice is retained in the source headers.
